Selecting Corpora

Open Source projects are codebases that are freely available for the public to view, use, distribute, and modify. Because of this, they are the perfect base to use as a corpus!

I chose 3 open source projects to first use as separate corpora to see if results would differ between projects (and their intended uses, since languages can specialise in a certain area of computing), then also chose to combine them into one larger corpus (referred to as the Amalgamation) for a more general selection. The open source projects I chose are detailed below.


TinyExpr

TinyExpr is a mathematical expression parser, used to evaluate math expressions. Written in C.

  • 2 source code files: 2222 total words, 348 unique words.

(Used this one as a first test for my tokeniser, since it was very small!)

Lua

Lua is a lightweight scripting language (interpreted line by line instead of all at once) and is very fast! Used in embedded systems (within smart devices, like microwaves) or embedded within video games to take care of game rules/level mechanics without having to recompile ‘heavier’ code. General purpose and has a very small memory footprint. Written in the ANSI C programming language.

  • 64 source code files: 100153 total words, 7155 unique words

SQLite

SQLite is a relational database management system.Iit is self-contained and serverless so all data is stored in one file rather than spread throughout multiple. Used for prototyping and small web-apps, or single user applications. Also very quick! Written in C.

  • 111 source code files: 1032132 total words, 33181 unique words

Amalgamation (All 3 projects, combined)

  • 177 source code files, 1134508 words, 37732 unique words.
