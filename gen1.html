The Evolution of Programming Languages

Bases and Binary

The number system we use regularly today is Base 10, meaning the place values of each digit are based on powers of 10. Even primitive computers, which used paper card and holes, used a form of this, like Babbage’s 1837 Analytical Engine, programmed by Ada Lovelace.

Binary is a base 2 number system, so the place values of each digit are based on the powers of 2.

Each digit can either be a 1 or 0 - computers use binary since switches can easily correspond to this system. Each switch can either be on or off - 1 = on, 0 = off. In the simplest terms, binary is the language computers can understand - unfortunately, it is very difficult and time consuming for us to read. We call this machine code, and the first generation of programming languages. Machine code was first used on the Mark 1 Computer at Harvard University.

Initially, programmers suffered through manually punching holes in tape/coding cards to feed into earlier computers. In 1951, Aiken created a ‘coding machine’ which automatically punched in operators, operands and signs using buttons so the human coder did not have to memorise long binary sequences…
