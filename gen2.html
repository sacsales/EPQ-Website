The Evolution of Programming Languages

Assembly Language

The second generation of software is characterised by assembly language - mnemonics, like ADD and LOAD, replaced long sequences of binary. “Short-order” code, created by Mauchy in 1949, was a set of subroutines that acted as ‘pseudocode’ - programming aids that allowed coders to use the aforementioned mnemonics. Grace Hopper coined the term “compiling routine” for translating code that more closely resembled English (that was easier for programmers to understand and write) into machine code for execution. In 1952, Glennie created the AUTOCODE system, which translated algebraic statements into the machine language of the Manchester Mark 1.
