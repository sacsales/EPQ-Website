The Evolution of Programming Languages

High-level Languages

The third generation of programming languages follows this path as well - designers of languages like FORTRAN, COBOL and ALGOL deliberately modeled language syntax on English grammatical structure and used English keywords for readability. [cite from babbage] The fourth generation continues the trend of the third, moving even closer towards natural language - languages like Kotlin, Java and Swift are even easier to debug, code and maintain.

The origin of early programming language designers such as Backus, Hopper and von Neumann are primarily American/British institutions. As a result, the majority of keywords that are common in syntax –as well as error messages, documentation and resources are heavily English based– which as we saw, is heavily influenced lexically by Latin.
