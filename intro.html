Introduction

EPQ: To what extent did Latin influence the syntax of modern programming languages, and how does this impact novice programmers with a first language other than English?

Computer Science is an ever-developing field. With the availability of programming resources on the internet, more and more people around the world are learning to code everyday, creating platforms and applications that help advance what we can accomplish with technology. Programming languages are what developers use to create these projects, but have we ever wondered about how these languages came to be? How did Latin, a now ‘dead’ language, impact the code we write today?

English is now the de facto lingua franca of the computing world - programming languages, the documentation that accompanies them, the resources we use to gain fluency and even the forums we use to discuss code are written predominantly in English. Of the 47 million developers around the world, how does the pervasiveness of English within the field of Computer Science affect those with a native language other than English?

Within this website, serving as a kind of interactive research paper, I’ve detailed my findings to the questions above. Navigate using the headings on the left and the next and back buttons.
