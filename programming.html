The Evolution of Programming Languages

Programming languages have developed over time, just as spoken languages have. From Charles Babbage's first concept of a general purpose computer, hand-punched code cards all the way to the modern languages we use today - each stage brings expanded the possibilties of what you could do with code. Different 'generations' of programming languages are detailed in this section.
